# Как запустить бота — пошагово

## Шаг 1. Создать бота в Telegram

1. Открой Telegram, найди **@BotFather**
2. Напиши ему: `/newbot`
3. Придумай имя (например: `Pocket Option Setups`)
4. Придумай username (должен кончаться на `bot`, например: `po_setups_bot`)
5. BotFather пришлёт **токен** — длинная строка вида `1234567890:AAE...xyz`
6. **Сохрани токен** — он понадобится на шаге 3

## Шаг 2. Загрузить код на GitHub

1. Зайди на github.com, нажми **New repository**
2. Название: `pocket-option-bot`, выбери **Private**
3. Нажми **Create repository**
4. Загрузи туда все файлы из этой папки (можно через кнопку
   **uploading an existing file** — перетащить файлы мышкой)

## Шаг 3. Запустить на Render

1. Зайди на render.com → **New** → **Web Service**
2. Подключи свой GitHub-репозиторий `pocket-option-bot`
3. Настройки:
   - **Runtime**: Python
   - **Build Command**: `pip install -r requirements.txt`
   - **Start Command**: `python main.py`
   - **Instance Type**: Free
4. В разделе **Environment Variables** добавь:
   - Key: `TELEGRAM_BOT_TOKEN`
   - Value: токен из шага 1
5. Нажми **Create Web Service** и подожди 2-3 минуты

## Шаг 4. Проверить

1. Открой своего бота в Telegram
2. Нажми `/start`
3. Появятся кнопки с парами — жми любую, бот кинет сетап

## Как пользоваться

- Клиент жмёт кнопку с парой → бот за пару секунд анализирует график
  и пишет: **ВВЕРХ или ВНИЗ**, экспирация **5 минут**, сила сетапа
- **Важно:** ставить только пары, у которых в Pocket Option выплата
  **+85% и выше**. Бот не видит выплаты — их надо смотреть на платформе
- Если бот пишет «чёткого сетапа нет» — лучше не ставить

## Что можно менять (файл config.py)

- `FOREX_PAIRS` / `CRYPTO_PAIRS` — список пар-кнопок
- `EXPIRY_MINUTES` — время экспирации (сейчас 5 минут)
- `MIN_SCORE` — строгость: выше = реже «рабочие» сетапы, но качественнее

После любого изменения — загрузи файл на GitHub заново,
Render сам перезапустит бота.
