# TUSA TRADE — инструкция запуска

## Шаг 1. Создать бота в Telegram

1. Открой Telegram, найди **@BotFather**
2. Напиши ему: `/newbot`
3. Придумай имя: `TUSA TRADE`
4. Придумай username (должен кончаться на `bot`): `tusa_trade_bot`
5. BotFather пришлёт **токен** — длинная строка вида `1234567890:AAE...xyz`
6. **Сохрани токен** — он понадобится на шаге 3

## Шаг 2. Загрузить код на GitHub

1. Зайди на github.com, нажми **New repository**
2. Название: `tusa-trade`, выбери **Private**
3. Нажми **Create repository**
4. Загрузи туда все файлы из этой папки (можно через кнопку
   **uploading an existing file** — перетащить файлы мышкой)

## Шаг 3. Запустить на Render

1. Зайди на render.com → **New** → **Web Service**
2. Подключи свой GitHub-репозиторий `tusa-trade`
3. Настройки:
   - **Runtime**: Python
   - **Build Command**: `pip install -r requirements.txt`
   - **Start Command**: `python main.py`
   - **Instance Type**: Free
4. В разделе **Environment Variables** добавь:
   - Key: `TELEGRAM_BOT_TOKEN`
   - Value: токен из шага 1
5. Нажми **Create Web Service** и подожди 2-3 минуты

## Шаг 4. Проверить

1. Открой своего бота в Telegram
2. Нажми `/start`
3. Появятся кнопки с парами — жми любую, бот кинет сетап

## Как пользоваться

- Клиент жмёт **🎯 ДАЙ СЕТАП** → бот за 2-3 секунды сканирует все монеты
  и кидает лучшую: **ВВЕРХ или ВНИЗ**, вход на **новой минуте**,
  экспирация **1 минута**
- **Важно:** ставить только пары с выплатой **+85% и выше**
  и только **БЕЗ пометки OTC** (OTC-котировки Pocket Option рисует сам,
  они не совпадают с реальным рынком)
- Если бот пишет «сетапа нет» — НЕ ставить. Это фильтр качества:
  лучше пропустить, чем слить

## Что можно менять (файл config.py)

- `PAIRS` — список монет для сканирования
- `MIN_SCORE` — строгость: выше = реже сетапы, но качественнее (сейчас 5 из 7)
- `RSI_*`, `VOLUME_SPIKE`, `MIN_ATR_PCT` — тонкая настройка фильтров

После любого изменения — загрузи файл на GitHub заново,
Render сам перезапустит бота.
